# Archive Directory

This directory contains archived code and files that have been moved out of the active codebase.

## Structure

- `2026-01-09/` - Phase 1 production hardening archives (January 9, 2026)
  - `empty-dirs/` - Empty directories that were archived
  - `hero-legacy/` - Legacy hero implementation components

## Restoration

To restore archived files, use `git mv` to move them back to their original locations.
Always check git history for the commit that moved the files for context.
